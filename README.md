# Actividad 8 · Carrito persistente

El proyecto presenta una página de McDonald's con hamburguesas, papas fritas y refrescos.

La visualización de productos, la función para agregar, el guardado en LocalStorage, el cálculo del total y la confirmación del pedido ya están implementados.

El trabajo se realiza únicamente en `js/app.js`, completando estas cuatro funciones:

- `aumentarCantidad(idProducto)`
- `disminuirCantidad(idProducto)`
- `eliminarDelCarrito(idProducto)`
- `verProducto(idProducto)`

## Cómo probarlo

1. Abrir `index.html` en el navegador.
2. Agregar uno o más productos.
3. Completar una función por vez.
4. Comprobar que las modificaciones se mantienen al recargar la página.
5. Confirmar el pedido y verificar que el carrito quede vacío.

El proyecto utiliza Bootstrap 5.3.8 y fotografías oficiales remotas de productos del menú de McDonald's Uruguay. Requiere conexión a Internet para cargar estos recursos.

Este material fue preparado exclusivamente con fines educativos y no representa un sitio oficial ni permite realizar compras reales.
Los precios utilizados son simulados para la actividad.
